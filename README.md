# 阿Der漫画创作 Skill

> 把成年人的小离谱，翻译成获得感。

这是一个用于创作中文公众号漫画的 Codex Skill，服务于原创 IP **阿Der / 阿得体面表达**。

它适合把一个生活或职场观察，继续拆成：

- 可点击的公众号标题
- 四格或六格漫画脚本
- 阿Der式现象命名
- 即梦AI无字画面提示词
- Canva排版文字
- 朋友圈/社群转发文案
- 建议发布时间与二次分发计划

## 这个 Skill 的创作方向

阿Der不是单纯讲“我好累”的丧漫画角色，而是一个：

> 疲惫但体面，狼狈但嘴硬，快碎了但还能总结的普通打工人。

内容优先选择有趣、具体、轻巧的日常观察。稳定的是阿Der的人设，变化的是每期观察到的荒谬现象。

推荐内容比例：

- 60% 日常离谱观察
- 25% 轻职场喜剧
- 15% 情绪共鸣

## 快速使用

把这个文件夹安装为一个 Codex Skill 后，可以直接这样调用：

```text
按 ader-comic-creator，帮我做一期公众号漫画。
```

完整调用示例：

```text
按 ader-comic-creator，帮我做一期《公司里最神秘的物种：一开会就说“我补充两句”的人》。

请输出：
1. 公众号标题和备选标题
2. 阿Der式现象命名
3. 四格漫画脚本
4. 即梦AI无字画面提示词
5. Canva排版文字
6. 结尾金句
7. 互动问题
8. 建议发布时间和二次分发文案
```

## 典型选题

- 《成年人最熟练的技能：假装刚看到消息》
- 《为什么公司茶水间总能听到真相》
- 《打工人的工位上，到底藏了多少求生装备》
- 《AI提高了我的效率，然后老板给了我更多活》
- 《周五5点的新需求，真会挑时间》

## 创作流程

```text
观察一个小现象
    ↓
给现象起一个一本正经的名字
    ↓
拆成四格或六格漫画
    ↓
用即梦AI生成无字画面
    ↓
用Canva添加中文旁白和对白
    ↓
按情绪窗口定时发布
    ↓
根据阅读、转发和留言继续找题
```

## 安装

将本仓库中的 `SKILL.md`、`agents/` 和 `references/` 保持在同一目录，然后放入 Codex 的技能目录：

```text
$CODEX_HOME/skills/ader-comic-creator
```

如果没有设置 `CODEX_HOME`，通常使用：

```text
~/.codex/skills/ader-comic-creator
```

安装完成后，重新打开 Codex 或新建对话，然后使用 `ader-comic-creator` 调用。

## 公众号入口

阿Der的持续内容入口：

**公众号：阿Der的体面表达**

事情可以不顺，表达必须高级。
