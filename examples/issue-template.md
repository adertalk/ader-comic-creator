# 阿Der漫画选题模板

把下面这段直接发给 Codex：

```text
按 ader-comic-creator，帮我做一期公众号漫画。

选题：
《公司里最神秘的物种：一开会就说“我补充两句”的人》

请使用阿Der的固定人设：
30岁左右普通中国打工人，微乱黑发，轻微黑眼圈，略皱白衬衫，松开的深蓝领带，疲惫但体面。

请输出：
1. 公众号标题首选和5个备选
2. 阿Der式现象命名和定义
3. 80-150字开头文案
4. 四格漫画脚本
5. 每格旁白和对白
6. 每格一条即梦AI无字画面提示词
7. 统一负面提示词
8. Canva排版文字
9. 结尾金句和互动问题
10. 建议发布时间、备用时间、二次分发窗口和转发文案

表达要求：
- 优先有趣和具体，不要写成纯丧文化
- 不使用“废物”“失败者”等身份标签
- 现实可以荒谬，表达要有获得感
- 中文对白不要放进AI画面，统一后期在Canva添加
```

## 输出判断标准

一篇合格的阿Der漫画应该满足：

- 标题一眼能看懂，不依赖栏目背景
- 前两格能让读者认出自己的日常
- 中间有一个具体而准确的荒谬细节
- 阿Der的反转不是鸡汤，而是体面化命名
- 结尾让读者愿意留言补充自己的经历
