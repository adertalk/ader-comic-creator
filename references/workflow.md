# 阿Der漫画公众号工作流

## Minimum Viable Production

Use this weekly flow:
1. Pick one high-comment topic.
2. Write one core insight.
3. Create a four-panel script.
4. Generate no-text images with Jimeng AI.
5. Add all Chinese text in Canva.
6. Publish as a公众号图文.
7. Track read count, shares, saves, and comments.
8. Convert comments into next topics.

## Article Structure

Use this default layout:

1. Cover/title area
   - Main title: clickable, specific, pain-driven
   - Subtitle: 职场荒谬图鉴 00X / 阿Der体面表达

2. Short opening
   - 80-150 Chinese characters
   - Start with the observed phenomenon
   - End with an 阿Der式命名

3. Comic panels
   - 4 panels for fast posts
   - 6 panels for richer topics
   - Each panel: one scene + one short caption or one dialogue beat

4. Final quote
   - One shareable sentence
   - Use the polished reframing system

5. Interaction question
   - Ask a concrete question that readers can answer from experience

## Canva Layout

Recommended canvas:
- Width: 1080 px
- Height: 3600-5200 px for 4-6 panels
- Panel image width: 960 px
- Left/right margin: 60 px
- Gap between panels: 50-80 px

Typography:
- Title: heavy sans-serif, 54-72 px
- Subtitle: 28-34 px
- Caption: 34-44 px
- Dialogue: 32-40 px
- Final quote: 46-60 px

Rules:
- Put all Chinese text in Canva, not in AI-generated images.
- Keep speech bubbles to 1-2 lines.
- Use white or light-yellow caption boxes with high contrast.
- Use a dark final quote area for stronger sharing.
- Export PNG; split long images if公众号 compression blurs the text.

## Publishing Cadence

Start with 3 posts per week:
- Monday: 职场荒谬
- Wednesday: 钱/AI/技能焦虑
- Friday: 互动话题/职业新名词

For early testing, prioritize comments over pure reads. The IP grows when readers contribute their own "体面表达".

## Data Notes

Track:
- Read count
- Share count
- Saves/favorites
- Comment count
- Which sentence readers quote back

Interpretation:
- High reads, low comments: title works, interaction weak
- Low reads, high comments: topic niche but sticky
- High shares: final quote or topic has public identity value
- Comments with reader stories: convert into next issue
